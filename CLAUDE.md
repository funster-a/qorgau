## Что это
Qorǵau — антифрод-платформа: помогает человеку распознать мошенническое
сообщение и строит национальный «радар» мошенничества из потока обращений.
Хакатон «AI for Kazakhstan», горизонт MVP — ~1 сутки.

## Стек (зафиксирован)
- **Бэкенд + движок + бот:** Go (один язык на всё серверное).
- **LLM:** Groq (OpenAI-совместимый API, эндпоинт `https://api.groq.com/openai/v1`). Бесплатный tier.
- **БД:** PostgreSQL, две схемы: `pii` (сырьё, шифр., TTL) и `analytics` (обезличенное).
- **Аналитика/дашборд:** Grafana поверх Postgres (графики без своего кода).
- **Веб-чекер:** статический `web/index.html` (или Next.js, если успеваем), дергает `POST /analyze`.
- **Android:** WebView-обёртка сайта в apk (в MVP — минимально).

## Границы MVP (что кодим ночью)
IN: TG-бот, веб-чекер, `POST /analyze` (Groq + эвристический фолбэк), запись
обезличенного сигнала в `analytics`, детекция аномалии (кампания), Grafana-дашборд.
OUT (роадмап, НЕ кодим): WhatsApp, звонилка, VPN/DNS, личные кабинеты,
threat-intel API, микросервис уведомлений (в MVP — простой TG-broadcast).

## Порядок сборки (делай строго так — сначала сквозной срез)
1. `docker-compose up` → Postgres + Grafana; применить `db/schema.sql`.
2. `api/` — поднять сервер, `POST /analyze` end-to-end (Groq + фолбэк + запись в БД).
3. `bot/` — TG-бот поверх `/analyze`.
4. Grafana — подключить Postgres, собрать 3 панели (динамика по схемам, топ схем, счётчики).
5. Детекция аномалии: фоновый пересчёт + флаг `campaign` + баннер.
6. `web/` — чекер с риск-метром; полировка; запись бэкап-видео демо.

## Ключевые правила (не нарушать — это фишки на защите)
- Сырой текст — только в `pii`, с TTL; в `analytics` — только обезличенные признаки.
- Телефоны/карты/IBAN маскировать ДО записи (`+7 7** *** ** 12`).
- При недоступности Groq — отвечать эвристическим фолбэком с пометкой `degraded`.
- Ответ `/analyze` — строгий JSON по контракту из `TZ.md` §5.2.

## Переменные окружения
См. `.env.example`. Обязательны: `GROQ_API_KEY`, `GROQ_MODEL`, `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`.

## Запуск
```
cp .env.example .env   # вписать ключи
docker-compose up -d   # postgres + grafana
cd api && go mod tidy && go run .        # бэкенд на :8080
cd bot && go mod tidy && go run .        # телеграм-бот
# web/index.html — открыть в браузере (или отдать статикой)
```
