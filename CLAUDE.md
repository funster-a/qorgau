## Что это
Антифрод-платформа: чекер сообщений (web + TG-бот) поверх Groq LLM с
эвристическим фолбэком + «национальный радар» — детекция волн мошенничества
из потока обезличенных сигналов, авто-предупреждение подписчиков.

## Стек (зафиксирован)
- Бэкенд + бот: **Go** (api/ и bot/ — отдельные модули, пакет main из несколько файлов).
- LLM: **Groq** (OpenAI-совместимый), промпт живёт в `engine/prompt.md`,
  грузится при старте (ENGINE_PROMPT_PATH), правится без пересборки.
- БД: **PostgreSQL**, схемы `pii` (шифр. pgcrypto, TTL) и `analytics` (обезличенное).
  Схему применяет сам API при старте (bootstrap из `db/schema.sql`) — Railway-совместимо.
- Веб: `web/index.html` (чекер) + `web/demo.html` (пульт) — vanilla, без CDN,
  отдаются самим API статикой.
- Аналитика: Grafana поверх Postgres, полный provisioning в `grafana/`.
- Деплой: Railway (api + bot + Postgres), `railway up`, см. `docs/DEPLOY.md`.

## Правила (фишки на защите — не ломать)
- Сырой текст — только в `pii`, шифрованный, с TTL. В `analytics` — только признаки.
- Телефоны маскировать ДО записи: `+7 7** *** ** 12`. Домены хранить целиком
  (не ПДн, главный признак кампании).
- Groq недоступен → эвристический фолбэк, `degraded: true`, UI показывает
  «базовый режим». Ошибка Groq с телом без choices не должна ронять хендлер.
- Ответ `/analyze` — строго по `docs/API.md`; ответ LLM прогоняется через
  normalize() (clamp score, неизвестная схема → other).
- Данные от LLM в DOM — только через textContent (не innerHTML).

## Грабли окружения (Windows-машина разработки)
- Порты 5432 И 5433 заняты локальными PostgreSQL → контейнер публикуется на **55432**.
- `go mod tidy` из Git Bash не видит go.mod → PowerShell + `go -C <dir>`.
- Кириллица в inline-JSON у curl из Git Bash корёжится → пейлоад в файл,
  `curl --data-binary @file`.

## Запуск
```
cp .env.example .env       # ключи; см. комментарии в файле
docker compose up -d       # postgres :55432 + grafana :3000
cd api && go run .         # :8080 — API + чекер + пульт
cd bot && go run .
cd api && go test ./...    # эвристика на engine/testset.json
```
