# Дизайн-система Qorǵau (направление: Consumer Safety)

> Источник истины по визуалу. Все страницы web/ обязаны выглядеть одной семьёй.
> Референс энергии: Revolut / Monzo / Wise — уверенно, дружелюбно, премиально,
> НЕ по-детски и НЕ «по-ИИшному».

## Что мы ЧИНИМ (антипаттерны — под запретом)
Прошлый фронт выглядел сгенерированным. Никогда:
- ❌ градиенты на тексте, светящиеся ореолы (glow), glassmorphism-размытия;
- ❌ эмодзи вместо иконок (эмодзи только в контенте/подсказках, НЕ в UI-хроме);
- ❌ сине-фиолетовые градиентные заливки «космос»;
- ❌ всё по центру + огромный герой с радужным заголовком;
- ❌ 10 разных цветов на экране, мягкие пастельные карточки без структуры.

## Что делаем ВМЕСТО
- Дисциплина цвета: тёмный фон + нейтральная шкала + ОДИН акцент. Семантика
  риска (красный/жёлтый/зелёный) появляется ТОЛЬКО в вердиктах, больше нигде.
- Сильная типографика и воздух. Контент по левому краю, честная сетка.
- Чёткие line-иконки (инлайн-SVG, stroke 1.75, сетка 24). Единый набор.
- Осмысленная микро-анимация на смену состояния, а не декоративное «плавание».
- Плоский цвет: большие спокойные блоки, акцент — только на интерактиве.

## Токены (CSS-переменные в web/assets/app.css)
Тёмная тема — основная. Значения — старт, дизайнер может чуть уточнить оттенки,
но НЕ ломая семантику и контраст (AA).

```
--bg:        #0B0E14;   /* глубокий ink-фон */
--surface:   #131924;   /* карточки */
--surface-2: #1B2330;   /* поднятые/hover */
--line:      #263041;   /* границы */
--line-soft: #1D2634;
--txt:       #EAF0F8;   /* основной текст */
--muted:     #93A0B4;   /* вторичный */
--muted-2:   #5E6B80;   /* третичный/плейсхолдер */

--accent:    #38E0C8;   /* БРЕНД-акцент: бирюза. Плоский, без градиента.
                           только кнопки/ссылки/фокус/активные состояния.
                           НЕ путать с зелёным риска. */
--accent-ink:#052B27;   /* текст на акценте */

--risk-low:  #2FD08A;   /* безопасно */
--risk-med:  #FFB020;   /* средний */
--risk-high: #FF5468;   /* высокий */
/* каждый риск-цвет ВСЕГДА в паре с иконкой/подписью — цвет не единственный сигнал */

--r-lg:20px; --r-md:14px; --r-sm:10px;
--shadow: 0 10px 30px rgba(0,0,0,.35);
--ease: cubic-bezier(.22,.9,.3,1);
--maxw: 720px;   /* контентные страницы */
--maxw-wide: 1040px; /* радар/дашборды */
```

Шрифт — системный стек (никаких внешних шрифтов): `-apple-system, "Segoe UI",
Roboto, sans-serif`. Моноширинный для кода/индикаторов: `ui-monospace, Consolas`.

Тип-шкала: 34/26/20/16/14/12.5, вес 800 для заголовков, 600 для акцентов,
межстрочный 1.5 для текста. Табличные цифры для метрик.

## Компоненты (классы в app.css — переиспользовать, не плодить)
- `.btn` (основная, плоский акцент), `.btn.ghost`, `.btn.lg`, состояние `.busy` (спиннер).
- `.card`, `.card.pad`, `.tile` (кликабельная плитка-раздел с иконкой).
- `.field` (обёртка input/textarea/select с фокус-кольцом акцента).
- `.chip` / `.chip.on` (примеры, табы-пилюли).
- `.gauge` — фирменный полукруглый спидометр риска 0–100 (SVG, анимация дуги +
  стрелки + счётчика). Единый на всех проверках. Реализация в app.js: `Gauge(el, score, level)`.
- `.badge.low|.med|.high` — бейдж уровня с иконкой.
- `.toast` — всплывающие уведомления (app.js: `toast(msg, kind)`).
- `.skeleton` — состояние загрузки (shimmer).
- `.tabs` — сегмент-контрол для раздела «Проверка».
- Иконки: инлайн-SVG symbol-спрайт в app.js (`icon('shield')`, `icon('phone')`,
  `icon('scan')`, `icon('link')`, `icon('message')`, `icon('card')`, `icon('alert')`,
  `icon('shield-check')`, `icon('graduation')`, `icon('scales')`, `icon('map-pin')`,
  `icon('radar')`, `icon('user-plus')`). stroke:currentColor, единый стиль.

## Общий каркас (app.js)
- `API` — same-origin (file:// → localhost:8080).
- `i18n` — единый словарь RU/QZ (все страницы берут отсюда), `localStorage['qorgau_lang']`.
- `nav([...])` — рендер верхней навигации (единая на всех страницах, подсветка текущей).
- `fetchJSON(path, opts)`, `toast()`, `Gauge()`, `renderVerdict(el, data)` —
  общий рендер вердикта (спидометр+флаги+объяснение+действия), чтобы все
  проверки показывали результат одинаково.
- Рендер данных из API — только `textContent`/`createElement`. Без innerHTML для данных.

## Информационная архитектура (навигация)
Продукт = жизненный цикл атаки. Верхняя навигация:
1. **Проверить** (`/` ведёт на лендинг; проверка — `/check.html`) — единый хаб:
   табы Сообщение · Ссылка · Скриншот · Номер · Карта. Один спидометр на всё.
2. **Тренажёр** (`/trainer.html`) — ИИ играет мошенника, разбор ошибок.
3. **Под защитой** (`/guard.html`) — привязка близкого, алерты. + «Мне звонят»
   (живой помощник) — `/live.html` или секция.
4. **Помощь после** (`/help.html`) — ИИ-чат первой юр-помощи, шаги, карта отделений.
5. **Shield** (`/shield.html`) — DNS-защита.
6. **Радар** (`/radar.html`) — национальная карта (About/масштаб).
Пароль (`/password.html`) — в футере/утилиты.

## Лендинг (index.html) — витрина
Не «герой с градиентом», а рассказ в три акта: **ДО → ВО ВРЕМЯ → ПОСЛЕ**.
Каждый акт — секция с крупной цифрой боли, 1-2 фичами, чёткой иконкой и CTA.
Сверху — короткий, сильный оффер и одна кнопка «Проверить сообщение».
Внизу — доверие (зоны данных, «текст удаляется через 24ч»), радар-тизер.
Мобайл-фёрст (жюри с телефона), но мощно на проекторе.

## Доступность и качество
- Контраст AA, фокус-видимость (кольцо акцента), клавиатура работает везде.
- `prefers-reduced-motion` — отключает анимации.
- Ноль внешних ресурсов (CSP-резилиенс демо): всё инлайн, шрифты системные,
  иконки/картинки — инлайн-SVG/data-URI. Единственные внешние URL допустимы
  только как ТЕКСТ примеров (не fetch).
