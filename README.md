# 🛡️ Qorǵau

Антифрод-платформа для хакатона «AI for Kazakhstan»: помогает человеку распознать
мошенническое сообщение и строит национальный «радар» мошенничества из потока обращений.
Полные требования — в [`TZ.md`](./TZ.md). Контекст для AI-агента — в [`CLAUDE.md`](./CLAUDE.md).

Сквозной срез собран и проверен: `web/бот → /analyze → БД → детекция кампании → Grafana`.

## Состав
- `api/` — Go-сервис: `POST /analyze` (Groq + эвристический фолбэк), маскирование
  индикаторов, запись обезличенных сигналов, детекция аномалий, `/stats/*`.
  Он же отдаёт веб-чекер статикой — на демо нужна одна ссылка.
- `bot/` — Telegram-бот на Go поверх `/analyze` (`/help`, `/campaigns`).
- `web/index.html` — веб-чекер с риск-метром и баннером активной кампании
  (он же контент для WebView-apk).
- `db/schema.sql` — две зоны данных (`pii` / `analytics`) + витрины для Grafana.
- `db/seed_demo.sql` — демо-данные + «всплеск» для показа детекции кампании.
- `engine/prompt.md` — системный промпт ИИ-ядра (главный IP; расширяйте примерами).
- `grafana/` — датасорс и дашборд, подключаются автоматически при `docker compose up`.
- `docker-compose.yml` — Postgres + Grafana.

## Что нужно вписать перед стартом
1. **Groq API-ключ** — бесплатно на console.groq.com → в `.env` (`GROQ_API_KEY`).
   Проверьте актуальное имя модели там же и впишите в `GROQ_MODEL`.
2. **Токен Telegram-бота** — у @BotFather → `.env` (`TELEGRAM_BOT_TOKEN`).

## Запуск (локально)
```bash
cp .env.example .env         # вписать ключи
docker compose up -d         # postgres :55432 + grafana :3000
# схема БД применяется автоматически при первом старте postgres

# бэкенд (.env подхватывается сам, из корня или из api/)
cd api && go mod tidy && go run .

# (в другом терминале) бот
cd bot && go mod tidy && go run .
```

- Веб-чекер: **http://localhost:8080/** (отдаётся самим API).
- Дашборд: **http://localhost:3000/d/qorgau-radar** (анонимный вход включён).

Демо-данные для дашборда:
```bash
docker exec -i qorgau-postgres-1 psql -U qorgau -d qorgau < db/seed_demo.sql
```

> **Про порт 55432.** На машинах разработчиков 5432 и 5433 почти всегда заняты
> локально установленным PostgreSQL, и контейнер молча проигрывает гонку за порт:
> сервис подключается к чужой базе и падает с `password authentication failed`.
> Поэтому публикуем заведомо свободный порт. Внутри docker-сети Grafana всё так же
> ходит на `postgres:5432`.

## Grafana
Датасорс и дашборд **подключаются сами** из `grafana/provisioning` — на защите
ничего настраивать руками не нужно. Дашборд «Qorǵau — национальный радар мошенничества»:
счётчики (обращения, доля высокого риска, активные кампании, доля базового режима),
динамика по схемам, топ схем, таблица кампаний и таблица обезличенных индикаторов.

Логин, если понадобится: `admin` / `admin`.

## Порядок работы для команды (рекомендация)
Разбейте по непересекающимся модулям, каждый — своя ветка/worktree:
- Человек A: `api/` + `engine/` (ядро, промпт, фолбэк, аномалии).
- Человек B: `bot/` + `web/` (каналы, UX).
- Человек C: Grafana-дашборд + `db/` (витрины, сиды, демо-сценарий).
- Ты (Android): WebView-apk обёртка `web/`.

Сначала соберите **сквозной срез** (web/bot → /analyze → БД → дашборд на сид-данных),
и только потом наращивайте. Так к утру гарантированно есть что показать.

## Сценарий демо (3 минуты)
1. Открываете веб-чекер / бота, вставляете реальную мошенническую СМС → мгновенный разбор (личная защита).
2. Переключаетесь на Grafana: «а теперь то, что видит вся сеть» → показываете всплеск и баннер кампании (коллективная защита).
3. Проговариваете приватность (зоны данных) и общественный профит (предотвращённый ущерб).

Заранее запишите **бэкап-видео** демо на случай проблем с сетью на сцене.
