# 🛡️ Qorǵau

**Цифровой телохранитель гражданина** — защита от мошенников на всех трёх
этапах атаки: до, во время и после. Плюс национальный радар, который строит
картину мошенничества из потока обращений.

Прод: **https://api-production-029f.up.railway.app** · Бот: **@QorgauHack_bot**

Хакатон «AI for Kazakhstan». Требования — [`TZ.md`](./TZ.md), архитектура —

## Продукт: защита по жизненному циклу атаки

### 🟢 ДО атаки — профилактика
- **Единая проверка** (`/check.html`): сообщение · ссылка · скриншот · номер ·
  карта — в одном хабе, один спидометр риска. Ссылка разбирается пассивно
  (whois-возраст домена, SSL, похожесть на бренд), скриншот — Groq vision
  (ловит поддельный интерфейс банка), номер — сколько раз встречался в жалобах.
- **Тренажёр** (`/trainer.html`): ИИ играет мошенника в безопасной игре,
  подсвечивает ошибки, в конце — оценка и разбор. Учишься не на своих деньгах.
- **Shield** (`/shield.html`): DNS-фильтр — фишинговые сайты не открываются
  вообще. Блок-лист пополняется из жалоб: пожаловался один — защищены все.
- **Пароль** (`/password.html`): проверка по утечкам (k-anonymity, пароль не
  покидает устройство).

### 🟡 ВО ВРЕМЯ атаки — реакция
- **Живой суфлёр** (`/live.html`): во время звонка вбиваешь фразы звонящего —
  ИИ мгновенно подсвечивает манипуляции и говорит «кладите трубку».
- **Защита близкого** (`/guard.html` + бот): привязываешь родителя (`/guardian`
  → `/protect`), при атаке на него тебе падает алерт — только факт и тип
  угрозы, без его переписки (приватность подопечного).

### 🔴 ПОСЛЕ атаки — последствия
- **Первая помощь** (`/help.html`): ИИ-юрист даёт пошаговый план (заблокировать
  карту, заявление, 102) с срочностью и контактами, находит ближайшие отделения
  по геолокации на мини-карте.

### 📡 Уровень страны
- **Радар** (`/radar.html`): тепловая карта Казахстана, детектор волн (z-score),
  авто-рассылка предупреждений подписчикам бота.
- **Threat-feed** (`/threat-feed`) — обезличенный фид индикаторов для банков.
- **Пульт демо** (`/demo.html`): засеять историю, запустить волну, фиче-флаги.

### 🔒 Приватность как архитектура
Зона `pii` (шифр. pgcrypto, TTL 24ч) отделена от `analytics` (обезличенное).
`/privacy/proof` — живое доказательство. Ядро: Groq LLM + эвристический фолбэк
(`degraded`) — демо не зависит от сети. Серверное — Go; фронт — vanilla, ноль
внешних зависимостей.

> Заглушки для демо (честно): телефоны/координаты отделений и BIN-таблица —
> заготовки, для прода нужны реальные справочники.

## Запуск локально

```bash
cp .env.example .env         # вписать GROQ_API_KEY и TELEGRAM_BOT_TOKEN
docker compose up -d         # postgres :55432 + grafana :3000
cd api && go run .           # API + веб на :8080 (схему БД применит сам)
cd bot && go run .           # бот (в другом терминале)
```

- Чекер: http://localhost:8080/ · Пульт: http://localhost:8080/demo.html
- Grafana: http://localhost:3000/d/qorgau-radar (anonymous viewer включён)

> Порт 55432 не опечатка: 5432/5433 на машинах разработчиков обычно заняты
> локальным PostgreSQL, контейнер молча проигрывает гонку за порт.

## Тесты и качество

```bash
cd api && go test ./...              # эвристика на engine/testset.json (50 кейсов)
GROQ_EVAL=1 go test -run Groq -v     # точность LLM-пути (медленно: лимиты free tier)
```

Тест-набор — реальные схемы РК: фейк-«служба безопасности» Kaspi/Halyk,
«мама, я в беде», фейк-инвестиции, взлом WhatsApp, работа с предоплатой —
и пограничные легитимные: настоящие OTP-СМС банка, уведомления eGov, доставка.

## Деплой

Продакшен — Railway (api + bot + Postgres), см. [`docs/DEPLOY.md`](./docs/DEPLOY.md).
Деплой из рабочей копии: `railway up --service api` / `--service bot`.

## Сценарий демо (3 минуты)

1. Чекер с телефона: реальная скам-СМС → мгновенный разбор (личная защита).
2. Пульт: «запустить всплеск» → через минуту баннер «Новая волна» в чекере,
   подписчикам бота прилетает предупреждение (коллективная защита).
3. Grafana: волна на графике. `/privacy/proof`: сырьё зашифровано и умрёт
   через 24 ч, в аналитике — только признаки (комплаенс).

Бэкап-план: эвристический фолбэк работает без интернета; бэкап-видео — записать.

## Структура

```

bot/     Go: Telegram-бот + broadcast предупреждений
engine/  prompt.md (системный промпт, правится без пересборки) + testset.json
web/     чекер + демо-пульт (vanilla, без зависимостей и CDN)
db/      schema.sql (зоны pii/analytics), seed_demo.sql
grafana/ provisioning датасорса и дашборда
docs/    архитектура, контракт API, деплой, девлог
```
