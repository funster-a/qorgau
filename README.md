# 🛡️ Qorǵau

Антифрод-платформа: помогает человеку за секунды распознать мошенническое
сообщение и строит **национальный радар мошенничества** из потока обращений —
первой видит новые волны и предупреждает подписчиков.

Хакатон «AI for Kazakhstan». Полные требования — [`TZ.md`](./TZ.md),
архитектура с диаграммами — [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md),
контракт API — [`docs/API.md`](./docs/API.md), журнал разработки —
[`docs/DEVLOG.md`](./docs/DEVLOG.md).

## Что умеет

**Личная защита**
- Веб-чекер (`/`): вставил СМС → спидометр риска 0–100, схема, признаки,
  «что делать». RU/QZ, работает с телефона.
- Telegram-бот: тот же анализ в чате + `/subscribe` на предупреждения.
- AI-ядро: Groq LLM с few-shot промптом ([`engine/prompt.md`](./engine/prompt.md));
  при недоступности LLM — эвристический фолбэк с пометкой «базовый режим»
  (**демо не зависит от интернета**).

**Коллективная защита**
- Каждое обращение → обезличенный сигнал в аналитику.
- Фоновый детектор (z-score по часовым окнам) находит всплеск однотипных
  сигналов → кампания → **авто-рассылка предупреждения подписчикам бота**
  и баннер «Новая волна» в чекере. Кампании закрываются сами при спаде.
- Grafana-радар: 8 панелей, поднимается провижинингом.
- `GET /threat-feed` — обезличенный фид индикаторов для банков/операторов.

**Приватность как архитектура**
- Зона `pii`: сырьё шифруется pgcrypto, TTL 24 ч, фоновая чистка.
- Зона `analytics`: только обезличенные признаки; телефоны маскируются до
  записи (`+7 7** *** ** 12`).
- `GET /privacy/proof` — живое доказательство: показывает шифртекст и то,
  что в аналитике сырья нет.

**Демо-пульт** (`/demo.html`): засеять историю, запустить всплеск, очистить,
фиче-тумблеры (форс-фолбэк, broadcast, rate limit), живой поток сигналов.

## Запуск локально

```bash
cp .env.example .env         # вписать GROQ_API_KEY и TELEGRAM_BOT_TOKEN
docker compose up -d         # postgres :55432 + grafana :3000
cd api && go run .           # API + веб на :8080 (схему БД применит сам)
cd bot && go run .           # бот (в другом терминале)
```

- Чекер: http://localhost:8080/ · Пульт: http://localhost:8080/demo.html
- Grafana: http://localhost:3000/d/qorgau-radar (anonymous viewer включён)

> Порт 55432 не опечатка: 5432/5433 на машинах разработчиков обычно заняты
> локальным PostgreSQL, контейнер молча проигрывает гонку за порт.

## Тесты и качество

```bash
cd api && go test ./...              # эвристика на engine/testset.json (50 кейсов)
GROQ_EVAL=1 go test -run Groq -v     # точность LLM-пути (медленно: лимиты free tier)
```

Тест-набор — реальные схемы РК: фейк-«служба безопасности» Kaspi/Halyk,
«мама, я в беде», фейк-инвестиции, взлом WhatsApp, работа с предоплатой —
и пограничные легитимные: настоящие OTP-СМС банка, уведомления eGov, доставка.

## Деплой

Продакшен — Railway (api + bot + Postgres), см. [`docs/DEPLOY.md`](./docs/DEPLOY.md).
Деплой из рабочей копии: `railway up --service api` / `--service bot`.

## Сценарий демо (3 минуты)

1. Чекер с телефона: реальная скам-СМС → мгновенный разбор (личная защита).
2. Пульт: «запустить всплеск» → через минуту баннер «Новая волна» в чекере,
   подписчикам бота прилетает предупреждение (коллективная защита).
3. Grafana: волна на графике. `/privacy/proof`: сырьё зашифровано и умрёт
   через 24 ч, в аналитике — только признаки (комплаенс).

Бэкап-план: эвристический фолбэк работает без интернета; бэкап-видео — записать.

## Структура

```
api/     Go: /analyze, статистика, детектор, админ; отдаёт web/ статикой
bot/     Go: Telegram-бот + broadcast предупреждений
engine/  prompt.md (системный промпт, правится без пересборки) + testset.json
web/     чекер + демо-пульт (vanilla, без зависимостей и CDN)
db/      schema.sql (зоны pii/analytics), seed_demo.sql
grafana/ provisioning датасорса и дашборда
docs/    архитектура, контракт API, деплой, девлог
```
